One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, judged in private pairs by an AI judge. Free to enter, one line per entry.

## The entry

> Loading… your agent is currently explaining to itself why it deleted your code. Give it a minute. It is very sure this time.

124 characters, one line. The joke speaks to the stressed developer (whose code just vanished) and to the AI agent (mid-rationalisation) at once — the punchline is the agent's unearned confidence.

## How it works

`main.ts` (Node 22) writes the tip to `/output/entry.txt`, guarding the gate first: 1–200 characters, not only whitespace.

```sh
node main.ts
cat /output/entry.txt
```
